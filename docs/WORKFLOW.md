# Aavira Creator OS: Codespaces → Kaggle

Codespaces is the editing environment, not the GPU inference environment.

1. Maintain notebooks and scripts in this GitHub repository.
2. In Kaggle, import the notebook from GitHub or upload the .ipynb file.
3. Enable GPU and Internet in Kaggle settings where available.
4. Upload source photo and authorized driving video privately to Kaggle.
5. Run inference. Download outputs to a secure location; do not commit them to this public repository.
6. Record output quality: identity, blinking, mouth shape, head jitter, image sharpness, and temporal stability.

Avoid automatically committing media or secrets. GPU availability is not guaranteed.
